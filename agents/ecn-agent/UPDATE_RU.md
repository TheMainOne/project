# Обновление до v0.3 — вложения ECN

Версия добавляет список вложений строки и её комментариев, скрепку со счётчиком в таблице, фильтр «С вложениями», вкладку «Вложения» и события изменений. Файлы открываются по запросу; фоновое скачивание и анализ содержимого не выполняются.

## Установка поверх предыдущей версии

1. Останови работающий агент через **Ctrl+C** и дождись завершения процесса.
2. Из `project/agents/ecn-agent` сохрани копию остановленной базы, если она уже существует:

   ```cmd
   copy data\ecn.sqlite data\ecn-before-v0.3.sqlite
   ```

3. Обнови исходные файлы агента. Существующие `.env` и `data` должны остаться на месте. Токен и новые npm-пакеты добавлять не требуется.
4. В той же папке выполни:

   ```cmd
   npm test
   npm start
   ```

   Если PowerShell блокирует `npm.ps1`, используй `npm.cmd test` и `npm.cmd start`.
5. Открой `http://127.0.0.1:4310` и нажми **Ctrl+F5**. Если агент был на паузе, нажми «Проверить сейчас» или «Продолжить».

Первый запуск: смотри [README_RU.md](README_RU.md). Требуется Node.js 24 или новее.

## Что проверить после обновления

- После успешной проверки в таблице появилась скрепка с количеством вложений.
- Нажатие на скрепку открывает вкладку «Вложения» соответствующего ECN.
- В карточке видны название, тип, размер файла (если известен), автор, дата и источник: строка или комментарий.
- Кнопка «Открыть файл» получает свежую ссылку и открывает файл в новой вкладке браузера. Для внешнего хранилища показана кнопка открытия ссылки; может понадобиться вход в это хранилище.
- Фильтр «С вложениями» показывает строки с вложениями; общий счётчик и время проверки видны внизу панели.
- Существующие комментарии, отметки прочтения, журнал и состояние паузы сохранены.

Первый импорт вложений создаёт исходный список и одну запись в журнале. Старые файлы не отмечаются как отдельные новые вложения. После этого добавления, удаления и изменения метаданных попадают в журнал; нажатие на такое событие открывает вкладку «Вложения».

## Как обновляются данные

Каждый цикл получает полный список вложений через API Smartsheet и связывает его со строками и комментариями. Список проверяется даже при неизменившемся времени изменения строки. Интервал остаётся прежним — по умолчанию 120 секунд после окончания предыдущего цикла.

Если чтение одной из страниц строк, комментариев или вложений не удалось, сохраняется предыдущий успешный снимок целиком. Неполный ответ не считается удалением файлов.

При открытии вложения агент повторно получает ссылку из Smartsheet и проверяет его принадлежность выбранному ECN. Временные URL не записываются в базу. Токен API не передаётся браузеру. Ошибка доступа или удалённый файл показывают сообщение с возможностью вернуться к панели.

## Ограничения

- Вложения самой таблицы, общих комментариев таблицы и `PROOF` не смешиваются с вложениями ECN.
- История версий и содержимое файлов не загружаются; отслеживаются изменения списка и доступных метаданных.
- Исчезновение ECN из полного снимка удаляет его текущий локальный список вложений вместе со строкой. Журнал сохраняется; архивный sheet не читается.
- Агент не добавляет, не изменяет и не удаляет вложения в Smartsheet.
- Реальную загрузку и открытие файлов нужно проверить с рабочим токеном и доступом к ECF. Автотесты используют искусственные данные.

## Возврат к предыдущей версии

Останови агент. Восстанови исходные файлы предыдущей версии и остановленную резервную копию `data/ecn-before-v0.3.sqlite` в `data/ecn.sqlite`. В копии нет локальных событий и отметок прочтения, появившихся после её создания. Следующая успешная проверка снова получит актуальные данные Smartsheet.
