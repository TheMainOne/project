# Обновление до v0.4 — автоматические номера ECN

Агент присваивает номер только при одновременном выполнении двух условий:

- `ECN Number` пуст.
- `Status` равен `Initial Review`.

Дополнительные требования к заполнению заявки не вводятся. Дата номера берётся из даты создания строки по времени Нью-Йорка. Счётчик отдельный для каждого дня, с учётом номеров рабочей ECF, ECN ARCHIVE и сохранённых резервов.

## Обновление

1. Останови агент через **Ctrl+C**, дождись завершения и сохрани копии имеющихся баз из папки `agents/ecn-agent`:

   ```cmd
   copy data\ecn.sqlite data\ecn-before-v0.4.sqlite
   if exist data\numbering.sqlite copy data\numbering.sqlite data\numbering-before-v0.4.sqlite
   ```

2. Обнови код, сохранив `.env` и папку `data`. Node.js 24+ остаётся обязательным; дополнительные пакеты не нужны.
3. Для автонумерации в существующем `agents/ecn-agent/.env` установи:

   ```dotenv
   ECN_AUTO_NUMBER=true
   ```

   Не заменяй существующий файл шаблоном — в нём находится рабочий токен. При отсутствии настройки или `false` агент только наблюдает. Для записи в заблокированную колонку ECN Number аккаунту токена требуется Admin/Owner и доступ к архиву.
4. Выполни:

   ```cmd
   npm.cmd test
   npm.cmd start
   ```

5. Открой `http://127.0.0.1:4310`, обнови страницу через **Ctrl+F5**. В заголовке должен появиться режим «Автонумерация». Если сохранена пауза, нажми «Продолжить».

## Поведение

Например, заявка создана 20 ноября, а агент обработал её 21 ноября. Если максимальный номер за 20 ноября в ECF/архиве — `20261120-03`, заявка получит `20261120-04`. Новому дню соответствует собственный счётчик с `01`; пропуски старых дней не заполняются.

Подходящие заявки, уже находящиеся в таблице при включении, также обрабатываются. До пяти строк за цикл; оставшиеся — в следующих циклах. Статусы, согласующие и другие поля агент не меняет. Каждое подтверждённое присвоение попадает в журнал. После записи перечитывается снимок для панели.

«Проверить сейчас» выполняет и наблюдение, и нумерацию, даже на паузе. «Пауза» запрещает следующие циклы, а текущий завершается. Для полного отключения нумерации установи `ECN_AUTO_NUMBER=false` и перезапусти агент.

## Сохранность счётчика и ошибки

Журнал назначений хранится в новой базе `data/numbering.sqlite`. Он сохраняет резерв за конкретной строкой до отправки PUT. Удалённый, отменённый или перенесённый ECN не освобождает номер. После остановки переносить и резервировать нужно обе базы: `ecn.sqlite` и `numbering.sqlite`.

Не запускай параллельный нумератор на другом компьютере и не выдавай номера вручную одновременно с агентом. Локальная блокировка предотвращает запуск второго исполнителя с той же базой на этом компьютере; условной атомарной записи пустой ячейки в API Smartsheet нет.

При недоступном архиве или неполном ответе номер не записывается. Если ответ на запись потерян, агент перечитывает строку без повторного PUT. Если результат нельзя подтвердить, нумерация останавливается и панель показывает ожидаемый номер для сверки. Не удаляй базу номеров для устранения ошибки. Подробности и порядок восстановления — в [README_RU.md](README_RU.md#автоматическое-присвоение-номера).

## Откат

Останови агент и восстанови код предыдущей версии. Базу `numbering.sqlite` сохрани: она содержит уже использованные номера и незавершённые операции. Откат кода или локального снимка не отменяет номера, уже записанные в Smartsheet. При возвращении к v0.4 используй сохранённый журнал номеров, а не более раннюю копию.
